# meal-planning

Costco Week Planner: a single-page meal planner for a family of three (two adults and a 1-year-old).

- Pick healthy dinners and breakfasts, including anti-inflammatory bowls and salads.
- See how many Costco packs the week needs, plus shelf life and freezer guidance.
- Tick items off a shopping list.

Live page: https://rjdunlap.github.io/meal-planning/

It is one static file (`index.html`) with no build step. Your plan and ticks are saved in the browser, per device.

Pack sizes and storage times are approximate. Check the package label. Not affiliated with Costco.
